# ЛОР-лікар Романенко Олена Юріївна — сайт

Односторінковий сайт для приватного кабінету ЛОР-лікаря у Бучі.

## Структура

```
├── index.html      # головна сторінка
├── css/
│   └── style.css   # стилі
├── js/
│   └── main.js     # інтерактивність
└── images/
    └── dr.JPG      # фото лікаря
```

## Як запустити

Просто відкрийте `index.html` у браузері або запустіть локальний сервер:

```bash
npx serve
# або
python -m http.server 8000
```

## Секції

- **Hero** — ім'я, спеціалізація, кнопки запису
- **Статистика** — досвід, пацієнти, рейтинги
- **Про лікаря** — освіта, кваліфікація, досвід
- **Послуги та ціни** — 8 карток з послугами
- **Запис на прийом** — форма з відправкою в Telegram
- **Відгуки** — 3 відгуки пацієнтів
- **FAQ** — 5 частих запитань (акордеон)
- **Контакти** — адреса, телефон, графік, карта
- **Footer** — навігація, копівайт

## Функціонал

- Адаптивний дизайн (desktop / tablet / mobile)
- Бургер-меню з анімацією
- Підсвітка активного пункту меню при скролі
- Scroll-reveal анімації елементів
- Лічильник статистики (counter animation)
- Маска телефону `0XX XXX XX XX`
- FAQ акордеон
- Відправка форми → Telegram бот
- Кнопка «Наверх»
- Валідація форми

## Telegram бот

Заявки з форми надходять у Telegram. Токен бота налаштовано в `js/main.js`.
